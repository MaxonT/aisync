aisync

One standup for all your AI coding tools. Claude Code, Codex and Cursor share one set of rules, one journal and one list of who is editing what, and hear what the others did while they work.

InstallSource on GitHub

Shared rulesOne rules file, copied into every tool's own rule file with a 3-way sync. Any agent can add a rule; conflicts are never overwritten.
Hash-chained journalEvery decision, blocker and commit in one append-only log. aisync verify catches any hand edit.
File claimsAgents claim files before editing. An overlapping claim exits with code 3, so the agent stops and coordinates.
Mid-session newsHooks tell a running Claude Code, Codex or Cursor session what the other tools just did. Silent when nothing changed.
