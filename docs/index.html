How it works

Step through it at your own pace (play, pause, arrow keys).

File claimsBefore editing, an agent runs aisync claim. An overlapping claim exits with code 3, so the agent stops and coordinates instead of colliding.
Hash-chained journalEvery decision, blocker and commit in one append-only log. Each event links to the one before it; aisync verify catches any edit.
Mid-session newsClaude Code, Codex and Cursor hooks tell a running session what the other tools just did. Silent when nothing changed, so a quiet hub costs no tokens.
Shared rulesAny agent can add a rule with aisync rule add; every tool's own rule file gets it on the next sync.

Install

Give this sentence to your AI agent. It reads the install page, does a dry run first and asks before it changes anything:

Read https://maxont.github.io/aisync/install and install aisync for me.

Or in a terminal: curl -fsSL https://maxont.github.io/aisync/install.sh | bash. Python 3.11+ and git, macOS or Linux, standard library only.
